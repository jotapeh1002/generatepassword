# 🔐 Password Generator

Gerador de senhas desenvolvido em **JavaScript** que permite criar senhas personalizadas de acordo com as preferências do usuário.

O projeto oferece diversas opções de configuração para gerar senhas mais fortes e seguras de forma rápida e simples.

---

## 🚀 Tecnologias utilizadas

- **JavaScript**
- **HTML5**
- **CSS3**

---

## 📌 Funcionalidades

✅ Geração automática de senhas  
✅ Escolha do tamanho da senha  
✅ Opção de incluir letras maiúsculas  
✅ Opção de incluir letras minúsculas  
✅ Opção de incluir números  
✅ Opção de incluir caracteres especiais  
✅ Interface simples e intuitiva  
✅ Cópia da senha gerada  

---

## ⚙️ Opções de personalização

O usuário pode escolher quais tipos de caracteres deseja utilizar:

- 🔠 Letras maiúsculas (`A-Z`)
- 🔡 Letras minúsculas (`a-z`)
- 🔢 Números (`0-9`)
- 🔣 Caracteres especiais (`!@#$%...`)

Também é possível definir o tamanho final da senha.

---

## 🧠 Como funciona

O gerador funciona criando uma lista de caracteres disponíveis conforme as opções selecionadas pelo usuário.

Exemplo:

```
Opções selecionadas:

Maiúsculas  ✅
Minúsculas  ✅
Números     ✅
Especiais   ❌


Resultado:

aB72kLm91
```

O JavaScript seleciona caracteres aleatórios até atingir o tamanho definido e retorna a senha final.
